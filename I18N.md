# Internationalization of the module hub

> 🇩🇪 [Deutsche Version](I18N.de.md)

The module hub publishes its maintainer-facing README in two languages:

- `README.md` is the English canonical source.
- `README.de.md` is the German mirror.

Keep both files synchronized when the catalog, installation contract, module authoring layout or trust guidance changes. Technical identifiers, paths, manifest keys, versions and code blocks remain unchanged. See the core repository's [`docs/I18N.md`](https://github.com/hydrahive/hydrahive2.0/blob/main/docs/I18N.md) for the general documentation convention.
